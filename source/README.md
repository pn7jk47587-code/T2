# App

Kleine Web-App mit lokaler Speicherung im Browser.

## Starten

```bash
npm install
npm run dev
npm run build
```

`npm run dev -- --host` macht die Entwicklungsseite im lokalen Netzwerk erreichbar.

## Struktur

```
src/
  core/         Speicherung, Typen, Register
  components/   gemeinsame Bausteine
  screens/      Seiten
  styles/       Farben und Layout
```
